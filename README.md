# Product Concepts

Интерактивные концепты продукта для ревью командой. Открываются как страница GitHub Pages.

Страница зашифрована: в репозитории лежит только шифротекст (AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600 000 итераций). Пароль и исходный HTML в репозиторий не попадают. Пароль выдаёт владелец.

## Обновить концепт

```bash
pip install cryptography
CONCEPT_PASSWORD='<пароль>' python3 tools/encrypt.py path/to/concept.html index.html
git add index.html && git commit -m "Update concept" && git push
```

Новый пароль = новая сборка с другим `CONCEPT_PASSWORD`; старые ссылки продолжат работать, старый пароль — нет.

## Выйти на устройстве

Галочка «Запомнить на этом устройстве» хранит ключ в браузере. Сбросить: открыть страницу с `?logout` в адресе.
